# Racing Pro

卡通风格的 3D 赛车模拟器（Three.js + TypeScript + Vite）。画一条赛道、调一台赛车、刷一个圈速。

在线地址：https://racing.oooo.so （经 Vercel 上的通用域名代理转发到 https://racing-pro.z1298554944.workers.dev）

```bash
pnpm install
pnpm db:migrate:local   # 初始化本地 D1（全球圈速榜）
pnpm dev                # http://localhost:5173，前端 + Worker API 一起跑
pnpm deploy             # 构建并部署到 Cloudflare Workers
pnpm db:migrate:remote  # 线上数据库迁移（新增 migrations 后执行）
pnpm models             # 用 Blender 重新生成 public/models/*.glb
pnpm check:physics      # 物理/调校参数的无头测试
```

托管在 Cloudflare Workers（静态资源 + `worker/index.ts` API），官方赛道的全球圈速榜与回放存储在 D1。

## 功能

- **赛道管理**：自由手绘（自动闭合、转换为样条控制点）、逐点编辑（拖动 / 插入 / 删除）、反向、设起点、随机生成、校验（长度、交叉、重叠、过急弯）。赛道自动生成路肩、缓冲砂石区、护栏、刹车距离牌、弯心锥桶、看台、维修区、广告牌和植被。
- **赛车管理（车库）**：12 组 50+ 项参数，全部进入物理模型：
  引擎扭矩曲线 / 红线 / 飞轮惯量 / 引擎制动；挡位数与齿比 / 主减速比 / 换挡时间 / 手自动；FWD/RWD/AWD 与四驱扭矩分配；开放 / 限滑 / 锁止差速器；质量 / 配重 / 重心高度 / 轴距 / 轮距；前后弹簧、压缩/回弹阻尼、防倾杆、车高、行程；外倾 / 前束 / 主销后倾；胎面抓地、胎宽、胎压、极限衰减；刹车力矩 / 前后比 / ABS / 手刹；前后下压力 / 风阻；转向角 / 速度 / 速度敏感 / 阿克曼；TCS / 稳定辅助。
  车库实时计算 0-100、0-200、极速、100-0 刹停距离、最大横向 G、各挡极速和扭矩/功率曲线。
- **无限计时赛**：越过起跑线开始计时，三个分段，实时与最佳圈差值，最佳圈幽灵车，出界/逆行/抄近路判定无效圈。
- **圈速榜与回放**：每条赛道 Top 20（IndexedDB），点击回放；斜俯视角 + OrbitControls 自由调节，跟随/全景；路线按速度（或油门/刹车）着色，自动标注刹车点和入弯速度；速度-距离遥测图（可点击跳转）；可与任意一圈对比（幽灵车 + 对比走线 + 实时差值）。

## 操作

| 键 | 功能 |
| --- | --- |
| W / ↑ | 油门 |
| S / ↓ | 刹车（静止时按住倒车） |
| A D / ← → | 转向 |
| 空格 | 手刹 |
| Q / E | 手动降 / 升挡 |
| 按住 R | 时间回退（越按越快，最多 20 秒，松开即从该时刻继续；不能跨越起跑线） |
| Backspace | 复位到赛道 |
| C | 切换视角 |
| G | 幽灵车开关 |
| M | 静音 |
| Esc | 暂停 |

支持手柄（左摇杆转向、RT/LT 油门刹车、按住 Y 回退）。

时间回退会恢复完整的车辆与计时状态（包括本圈是否有效），使用次数会记录在圈速榜上（⏪n）。

驾驶辅助分 新手 / 标准 / 专业 三档，可在出发界面或暂停菜单切换。

## 物理模型

`src/car/physics.ts`：四轮车辆模型，480 Hz 子步进。车身有升沉/俯仰/侧倾三个自由度，由四角弹簧-阻尼与防倾杆支撑，载荷转移自然产生；轮胎为简化 Pacejka 组合滑移模型（载荷敏感、外倾、胎压、胎宽）；轮速采用隐式积分；差速器通过隐式扭矩传递实现开放/限滑/锁止；空气动力下压力含离地高度与 Rake 效应。

## 模型

`blender/build_models.py` 用 Blender 以程序化方式建模（赛车车身、轮毂/轮胎/刹车卡钳、树木、看台、维修区、龙门架、广告牌、轮胎墙、锥桶、云、热气球），导出为 GLB，游戏内统一转换为卡通着色 + 描边。
